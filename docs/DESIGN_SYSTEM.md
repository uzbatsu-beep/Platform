# Правила интерфейса NEON (DESIGN_SYSTEM)

## 1. Утверждённая компоновка: Вариант C — Engineering Workspace Shell
- **Сворачиваемая левая навигация:** модули и разделы в рамках прав пользователя, сворачивается в компактный Rail.
- **Верхняя панель (Top Bar):** глобальный поиск / Command Palette (`Ctrl+K`), переключатель контекста площадки/подразделения, уведомления, переключатель светлой/тёмной темы и плотности (`compact` / `comfortable`), профиль пользователя.
- **Рабочая область с вкладками:** открытие нескольких карточек/разделов с синхронизацией активной вкладки с URL в [TanStack Router](https://tanstack.com/router/latest/docs/how-to/integrate-shadcn-ui).
- **Правая контекстная панель (Inspector Drawer):** просмотр свойств, истории и вложений без потери контекста таблицы/дерева.
- **Настраиваемый Dashboard:** сетка модульных виджетов с сохранением пользовательской раскладки в БД.

## 2. Инженерная типографика, темы и Air-gapped ресурсы
- Все шрифты (локальные `woff2` с поддержкой кириллицы и `tabular-nums`), иконки и стили входят в локальный бандл Vite — **нулевые обращения к внешним CDN**.
- Светлая и тёмная темы с контрастностью WCAG AA (≥ 4.5:1), без избыточных декоративных анимаций.

## 3. Локализация (i18n) с первого дня
- Основной язык MVP — **русский (`ru`)**.
- Запрещено жёстко зашивать пользовательские строки в TSX-компонентах и backend-ответах: весь UI использует типизированные i18n-ключи (`i18next`), backend возвращает машинные коды ошибок и ключи локализации. Подключение английского (`en`) в следующей фазе потребует только добавления словаря без рефакторинга компонентов.

## 4. Сложные компоненты
- **Таблицы:** [TanStack Table](https://tanstack.com/table/latest) (фиксированная мажорная версия в `pnpm-lock.yaml`) + [TanStack Virtual](https://tanstack.com/virtual/latest/docs/framework/react/react-virtual) (`useFlushSync: false` для React 19).
- **Деревья оборудования:** виртуализированное дерево с клавиатурной навигацией (`↑/↓/←/→`) и фильтрацией.
- **Формы:** React Hook Form + Zod, защита от потери несохранённых данных, горячие клавиши (`Ctrl+S`).
