# ADR-004: Границы модулей, ModuleManifest и разделение User / Employee

- **Статус:** Утверждено (Decision Gate NEON)
- **Дата:** 2026-11-20

## Решение
1. Все модули регистрируются через `ModuleManifest` и зависят только от `platform-sdk` и публичных контрактов разрешённых зависимостей.
2. `User` (учётная запись, сессии, RBAC) принадлежит `platform-core`; `Employee` (кадровые данные) принадлежит исключительно `mod-hr-org` (Phase 2). В `User` хранится только опциональная ссылка `employee_id: Option<EmployeeId>`.
3. Внутри одного Rust-процесса изоляция обеспечивается границами Cargo crates, CI-проверкой SQL и серверным RBAC.
