# ADR-005: AuthProvider, Bootstrap/Recovery, RBAC и честный статус аудита

- **Статус:** Утверждено (Decision Gate NEON)
- **Дата:** 2026-11-20

## Решение
1. Аутентификация строится через абстракцию `AuthProvider` (MVP: локальный Argon2id + защищённые серверные сессии; Phase 2: OIDC/LDAP).
2. Первоначальная настройка и восстановление администратора выполняются безопасно через `neon admin init` / `admin reset-password` (единый бинарник Standalone) и `neon-cli` (Server) на общей библиотеке `platform-cli-core` (см. `ADR-011`) с отзывом сессий и записью в аудит.
3. RBAC формата `<module>:<resource>:<action>` + `Scope` (`Site`/`Department`) проверяется на сервере.
4. Аудит в MVP защищён как append-only на уровне приложения и прав БД с настраиваемой ретенцией; **криптографическая неизменяемость не заявляется**, SIEM-интеграция отложена на Phase 2.
