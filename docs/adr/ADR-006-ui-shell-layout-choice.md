# ADR-006: Утверждение компоновки интерфейса — Вариант C (Engineering Workspace Shell)

- **Статус:** Утверждено (Decision Gate NEON)
- **Дата:** 2026-11-20

## Решение
Утвердить **Вариант C (Engineering Workspace Shell)**: сворачиваемая левая навигация, верхняя панель с `Ctrl+K` поиском и контекстом площадки/цеха, рабочая область с вкладками, правый контекстный Inspector Drawer и настраиваемый Dashboard с виджетами.
