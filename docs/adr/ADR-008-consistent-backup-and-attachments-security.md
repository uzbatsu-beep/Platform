# ADR-008: Согласованный бэкап БД + вложений и безопасность документов

- **Статус:** Утверждено (Decision Gate NEON)
- **Дата:** 2026-11-20

## Решение
1. Файловые вложения хранятся в **Content-Addressed Immutable Blob Store (SHA-256)** вне webroot с отложенным GC (tombstone + grace period).
2. Согласованный бэкап выполняется в порядке: консистентный снимок БД (`VACUUM INTO` / `pg_dump`) → копирование активных блобов по ссылкам снимка → `backup-manifest.json` с SHA-256 → автоматическая проверка восстановления.
3. В MVP принимаются `PDF`, `PNG`, `JPG/JPEG` и инженерные форматы (`DXF`, `DWG`, `STEP`, `CSV`, `TXT`, `DOCX`, `XLSX`) с безопасным скачиванием (`Content-Disposition: attachment`, проверка magic bytes, настраиваемые лимиты по умолчанию 25/50/100 МБ, без серверного парсинга и CAD-просмотрщика DXF/DWG).
