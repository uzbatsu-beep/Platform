# ADR-009: Air-gapped Deployment и готовность к экспорту/импорту данных

- **Статус:** Утверждено (Decision Gate NEON)
- **Дата:** 2026-11-20

## Решение
1. **Air-gapped deployment** — обязательный стандарт: локальная поставка всех ассетов UI, проверка в CI, офлайн-дистрибутивы с `SHA256SUMS` и регламент офлайн-обновления.
2. Полноценная синхронизация Standalone ↔ Server не входит в MVP, но уже в Phase 1 все сущности получают стабильные `UUIDv7`, `source_instance_id` и `schema_version` для будущего проверяемого экспорта/импорта с манифестом и анализом конфликтов. Прямой перенос файла SQLite в PostgreSQL запрещён.
